# Fixit Bhera - HTML / CSS / JavaScript Website

Production-ready, lightweight, zero-dependency static website for **Fixit Bhera** (Doorstep Home Services in Bhera & Surrounding Villages).

## Files Included:
1. `index.html` - The complete HTML5 structure, responsive layout, modal dialogues, English/Urdu bilingual support.
2. `style.css` - Custom styles, typography support for Urdu/English, clean scrollbars.
3. `app.js` - Pure Vanilla JavaScript handling service catalogs, area selection, WhatsApp pre-filled dispatches, and genuine customer feedback.

## How to Run:
Simply double-click `index.html` in any web browser (Chrome, Edge, Safari, Firefox). No build tools, Node.js, or server required!

## Key Features:
- **5 Core Services**: Electrician, Plumber, AC Technician, Appliance Repair, Home Cleaning.
- **Bhera Coverage**: Bhera City (All 8 gates) + Miani, Hazurpur, Zain Pur, Ali Pur, Melowal, Rakh Chargah.
- **Direct Contact**: Phone Call (`0300-7864321`) & WhatsApp instant dispatch (`923007864321`).
- **Zero Dummy Data**: Clean, transparent pricing (Rs. 1,500 - 4,000 PKR), 30-day warranty, and cash on service.
